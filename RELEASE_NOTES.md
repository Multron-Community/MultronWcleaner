## Multron Win Cleaner 1.29.3 Update

### Built on .NET 10
- **No .NET runtime to install anymore.** Multron Win Cleaner now runs on .NET 10 (support for .NET 8 ended in November 2026) and brings the runtime with it, so it starts on any 64-bit Windows 10 or 11 PC without installing the .NET Desktop Runtime first. The download is larger because of this.

### Fixes
- **No more crash when ending an app.** **End Task** in the Memory Cleaner widget and Performance Monitor could close Multron Win Cleaner when Windows denied access to one of the app's processes. Such apps are now listed as *access denied* instead.
- **Opening tools during a scan is safer.** Opening Large File Finder or Duplicate File Finder no longer reloads the whole Settings window in the background, which could disturb a running scan and is the likely cause of a crash when Large File Finder was opened during a scan with Malware Scan.
- **Utilities stay usable during the malware step.** While the main scan was running Malware Scan, the Firewall Rule Cleaner, Shortcut Fixer and Security Check buttons all turned into **Cancel** and stopped the main scan. They now work normally during the malware step.
- **Cancel tool scans from the main window.** While Large File Finder or Duplicate File Finder is scanning, the main window already showed its progress, but the Scan button stayed *Scan*. It now turns into **Cancel** and stops that scan, and comes back when the tool is done.
- **No update check when updates are off.** When both automatic app updates and automatic database updates are turned off, the loading screen no longer shows *Checking for updates* and no longer checks or downloads anything (the database is still downloaded once if it is missing).
- **Errors no longer close the app.** If something unexpected goes wrong, Multron Win Cleaner shows a short message and keeps running, and the details are saved to `crash.log` in the program folder so the problem can be reported and fixed.

### Updating
- **From 1.29.2 or earlier:** the app updates itself to 1.29.3 as usual (Settings > App Updates).
- **New installs:** download `mwc_setup.exe` (installer) or `mwc.zip` (portable) below.
