## Multron Win Cleaner 1.29.5 Update

### Changes
- **Security fixes have their own activity list.** Security fixes used to be written into the *Activity* list of System Optimization, mixed with the optimization changes. They are now shown in a separate *Activity* list in the Security Check card, which also lists fixes that failed and when the fixes were undone. Fixes made from the main window are listed there too. Security fixes already in the System Optimization list are moved there automatically.
- **ReScan button in Large File Finder and Duplicate File Finder.** After a scan, a **ReScan** button appears next to the main button, so the same folders can be scanned again with one click. In Duplicate File Finder this means you no longer have to clear the list first when the main button already says **CLEAN**.

### Fixes
- **Duplicate File Finder button no longer shows Cancel for nothing.** While the main scan was at the Malware Scan step, the Duplicate File Finder button turned into **Cancel** even though Duplicate File Finder was not scanning, and pressing it stopped the main scan. The button now stays **Scan** during the malware step, so Duplicate File Finder can be used normally.

### Updating
- **From 1.29.4 or earlier:** the app updates itself to 1.29.5 as usual (Settings > App Updates).
- **New installs:** download `mwc_setup.exe` (installer) or `mwc.zip` (portable) below.
