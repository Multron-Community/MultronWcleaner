## Multron Win Cleaner 1.29.4 Update

### Fixes
- **Same RAM usage everywhere.** The Memory Cleaner window, the Memory Monitor widget and Task Manager now show the same RAM percentage. The Memory Cleaner window used to keep the value from right after a cleaning (for example 42% while the widget and Task Manager showed 35%); it now refreshes every 2 seconds while it is open, together with the CPU load.
- **Full version on the loading screen.** The loading screen now shows the full version number (for example *v1.29.4 beta*) instead of only *v1.29*.
- **Realistic remaining time in Malware Scan Cloud.** When the scan reached the files that have to be uploaded, *Remaining* kept showing *<1m* for many minutes because it was based on the fast start of the scan. It is now based on the speed of the last minute, so it shows how long the uploads will really take.
- **Clearer Security Check result after fixing.** After fixing settings, Security Check said *No insecure Windows settings were found. 7 fixed.*, which sounded contradictory. It now says *7 fixed. No insecure Windows settings are left.*
- **Tool results show up during a scan.** When Large File Finder or Duplicate File Finder (or another Utilities tool) finished while the main scan was still running, for example during the Malware Scan step, the main window showed nothing about it. Its result now appears as a card in the main window. The main **Cancel** button still stops the main scan; a tool's own scan is stopped with **Cancel** in the tool.
- **Duplicate Files step no longer skipped silently.** If Duplicate File Finder was already scanning when the main scan reached the Duplicate Files step, the step was skipped without any message. It now says that it was skipped and that the results are in Duplicate File Finder.
- **Clearer name for the DISM option.** The *Windows Repair (DISM)* option also contains *Clean up old Windows update files*, which did not fit its name. It is now called *Windows Component Store (DISM)*, the same name its result card already used, and its description mentions both the cleanup and the repair.

### Updating
- **From 1.29.3 or earlier:** the app updates itself to 1.29.4 as usual (Settings > App Updates).
- **New installs:** download `mwc_setup.exe` (installer) or `mwc.zip` (portable) below.
